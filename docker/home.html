jss-devtools

Công cụ dòng lệnh cho các repository JavaScript.

Cài đặt cho user hiện tại, không cần sudo:

curl -fsSL https://jss-devtools.jjuidev.com/install.sh | sh

Yêu cầu Node >= 24.11.0, cùng curl hoặc wget.

Sau khi cài, lệnh nằm ở ~/.local/bin/jss-devtools. Thêm thư mục đó vào PATH nếu chưa có.

Mã nguồn: github.com/jearax/jss-devtools2
